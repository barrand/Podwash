## Labeling pipeline

1. **`llm_proposed.json`** — first-pass spans from `ad_eval_label.py` (rule-based patterns; optional OpenAI when `OPENAI_API_KEY` is set). **Not** derived from `HeuristicContentSegmenter`.
2. **`MARKUP.md`** — human review pack per episode (agree / disagree / edit per span).
3. **`golden.json`** — approved ground truth only when `"status": "human-approved"` and `reviewer` is a real human. Current bootstrap copies may use `"status": "proposed"` or `"status": "provisional"` until you review `MARKUP.md` and re-run `ad_eval_golden.py --from-markup` or hand-edit.

**Anti-cheat:** Do not promote heuristic output into goldens. Goldens must be human-approved (or explicitly marked provisional for interim scoring only).

## Scoring

- **`heuristic.json`** — `HeuristicContentSegmenter` logic via `scripts/ad_eval_heuristic.py` (mirrors Swift `heuristic-cue-v3`).
- **`metrics.json`** — per-episode precision/recall with temporal IoU ≥ 0.5 (greedy 1:1), FP/FN excerpts, cue audit. Treat existing metrics as stale if the episode `golden.json` is not `"human-approved"`.
- **`metrics_summary.json`** — macro averages across four episodes. Treat as stale until all included goldens are human-approved and re-scored.

## Your review workflow

```bash
# 1. Open each MARKUP.md, check [x] agree on spans you accept
# 2. Promote agreed spans to golden.json
python3 scripts/ad_eval_golden.py --from-markup --reviewer "your-name"

# 3. Re-score
python3 scripts/ad_eval_score.py
```

## Files per show folder

- `meta.json` — feed + episode context passed to labeling
- `transcript.json` — `[TimedWord]` JSON
- `transcript.txt` / `transcript.md` — readable transcript
- `llm_proposed.json` — proposed spans
- `MARKUP.md` — review UI
- `golden.json` — ground truth (provisional until reviewed)
- `heuristic.json` — segmenter predictions
- `metrics.json` — scores vs goldens
